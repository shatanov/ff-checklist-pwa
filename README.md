# FF Checklist PWA

Offline-first PWA для проверки фулфилмента.

## Что работает офлайн

- интерфейс и статические файлы кэшируются Service Worker;
- ответы, комментарии и итог осмотра сохраняются локально;
- фотографии сохраняются в IndexedDB на устройстве;
- приложение запрашивает persistent storage, если браузер это поддерживает;
- после первого полного открытия приложение можно запускать без интернета.

## Установка на iPhone

1. Открыть GitHub Pages в Safari.
2. Дождаться полной загрузки страницы.
3. Нажать «Поделиться» → «На экран Домой».
4. Запустить приложение с домашнего экрана.
5. После этого проверить работу в авиарежиме.

Важно: не удаляйте данные Safari/PWA и само приложение, если хотите сохранить локальные фото и заполненный чек-лист.
